Aide et installation

Installer Solve It Poker

Quel fichier prendre ?

  • Mac (puce Apple ou Intel, macOS 12 ou plus récent) : Solve It Poker pour Mac (.dmg). Un seul fichier pour tous les Mac.
  • PC Windows 10 ou 11 (64 bits) : Solve It Poker pour Windows (.exe)

Sur Mac

  1. Double-clique sur le fichier .dmg téléchargé. Une fenêtre s'ouvre avec l'application Solve It Poker et le dossier Applications.
  2. Glisse Solve It Poker sur le dossier Applications.
  3. Ferme la fenêtre, puis éjecte « Solve It Poker » dans la barre latérale du Finder.
  4. Ouvre Solve It Poker depuis le dossier Applications. À la première ouverture, macOS te demande si tu veux vraiment ouvrir une application téléchargée sur Internet : clique Ouvrir. Ensuite, elle s'ouvre normalement.

Sur Windows

  1. Double-clique sur le fichier .exe téléchargé.
  2. Windows affiche « Windows a protégé votre ordinateur » (c'est le filtre SmartScreen de Windows) : clique Informations complémentaires, puis Exécuter quand même. Ce message apparaît parce que l'application n'est pas encore signée pour Windows : il ne dit pas qu'elle est dangereuse, seulement qu'elle est inconnue de Microsoft.
  1. Suis les étapes de l'installation.
  2. Lance Solve It Poker depuis le menu Démarrer ou le raccourci du Bureau.

Retrouver tes mains

L'application cherche toute seule tes historiques de mains et analyse aussi celles qui sont déjà sur ton ordinateur. Si elle ne les trouve pas : onglet Tracker > Choisir un dossier.

  • Winamax : Options > Tracker indique le dossier des historiques.
  • PokerStars : Options > Historique des mains > coche « Sauvegarder l'historique » et « Sauvegarder les récapitulatifs de tournoi », et choisis l'anglais comme langue des historiques.
  • Gains en euros des tournois : onglet Rapports > Chercher mes résultats de tournoi.

Faire marcher le HUD

Sur Mac : trois autorisations

Le HUD doit savoir où sont tes tables. macOS demande ton accord pour ça :

  1. Accessibilité : Réglages Système > Confidentialité et sécurité > Accessibilité, ajoute « Solve It Poker » et coche la case.
  2. Automatisation : même rubrique, « Automatisation », autorise « System Events » pour Solve It Poker.
  3. Enregistrement de l'écran (si tu joues plusieurs tables de Spin, ou sur les tables Escape, où le HUD lit les pseudos à l'écran ; le nom exact varie selon la version de macOS) : même rubrique, autorise Solve It Poker. L'application lit les pseudos pour reconnaître chaque table. Rien n'est enregistré ni envoyé.

Quitte ensuite l'application (⌘Q) et relance-la.

Si le HUD ne s'affiche pas alors que Solve It Poker est coché dans Accessibilité : retire-le (–), ajoute-le à nouveau (+), coche-le, puis relance l'application. C'est à faire une seule fois : l'application est signée par un certificat Apple, l'autorisation est conservée d'une version à l'autre.

Sur Windows

Aucune autorisation à donner.

Conseils pour les deux

  • Winamax : désactive le mode « playground ». Il regroupe toutes les tables dans une seule fenêtre, et le HUD ne peut pas s'y placer.
  • Plusieurs tables : si un HUD affiche les joueurs d'une autre table, clique sur « ⇄ Pas la bonne table ? » en haut de la table et choisis les bons adversaires.
  • Les tables réduites ou placées sur un autre bureau n'ont pas de HUD. Quand deux tables se chevauchent, seul le HUD de celle de devant reste visible.
  • PokerStars : n'utilise pas le HUD à leurs tables tant que Solve It Poker n'est pas sur leur liste de logiciels autorisés. L'analyse de tes mains après la session reste possible.

Besoin d'aide ?

Écris à contact@solve-it-poker.com avec :

  • une capture d'écran du message ou du problème ;
  • ton système (Mac ou Windows, et sa version) ;
  • ta salle (Winamax ou PokerStars).

Si le HUD se place mal : Tracker > Mon HUD > copie la liste des fenêtres vues, et envoie-la avec une capture de ta table.
